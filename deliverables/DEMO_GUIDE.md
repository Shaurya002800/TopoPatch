# TopoPatch faculty demonstration

## Start

From the project folder, run:

```sh
python3 -m topopatch serve --port 8767 --db artifacts_private/faculty-demo.sqlite
```

Open http://127.0.0.1:8767. If the port is occupied, stop the previous server with Ctrl+C or choose another port. Use a new database filename to start from epoch zero. Python 3.11+ is sufficient; the default demonstration needs no downloaded models.

## Five-minute walkthrough

1. Explain the technical problem: partial embedding-model migration can alter merged result ranks, including results whose source text did not change.
2. Show the initial 40 objects, zero target memberships, and four protected-query checks. This is an authored functional fixture using lexical encoders.
3. Click **Analyze candidates**. Show 14 charged target encodings, one admissible singleton action and 13 rejected actions.
4. Click **car-guide REJECTED**. The password-policy result violates its maximum rank. Commit is disabled. The API independently rejects unsafe commits too.
5. Click **password-policy ADMISSIBLE**, then **Commit inspected state**. Show target membership 1 and epoch 1, with four passing constraints.
6. Export evidence. The JSON includes model identities, source fixture, counters, previews and commit events.
7. Click **Roll back latest commit**. Target membership returns to zero and epoch advances to 2. Encoding costs remain charged.
8. Show Section 8 of the disclosure. Explain that protected-query correctness is demonstrated, while the broader quality/cost benefit is not.

## Additional evidence modes

Use a new database for each experiment:

```sh
python3 -m topopatch serve --port 8768 --db artifacts_private/exhaustive-demo.sqlite --evidence exhaustive
python3 -m topopatch serve --port 8769 --db artifacts_private/strict-demo.sqlite --evidence strict
```

Exhaustive mode charges all 40 target embeddings before strict admission. Strict mode without exhaustive coverage refuses unresolved candidate evidence. Complete coverage does not imply full-B-equivalent mixed retrieval.

`--fusion continuity` selects the experimental shadow-A policy. It is a separate embodiment and carries extra legacy ranking/storage cost. Do not present it as the frozen A-removal path.

## Reproduce checks

```sh
python3 -m unittest discover -s tests -v
python3 -m scripts.prove_prototype
python3 -m topopatch benchmark --output artifacts_private/new-benchmark.json
```

The proof command writes `artifacts_private/prototype-proof-trace.json` and asserts each local state transition. See `PROTOTYPE_PROOF.md` for the measured sequence and its scope. The optional neural evaluation requires sentence-transformers and local model snapshots. See README for the research CLI. Historical experiment files record the exact sample IDs, source hash, model identities and metrics; some older runs used different splits and cannot be regenerated by assuming today's CLI defaults are identical.

## Documents

- `TopoPatch_IDF_B_completed.pdf`: a detailed seventeen-page IDF-B document following VIT's numbered sections, including a fresh functional proof trace and the original VIT TRL grid marked at TRL 3.
- `TopoPatch_IDF_B.docx`: editable version of the same document.
- `TopoPatch_project_and_evidence.zip`: source, tests, screenshots, benchmark evidence, documents and SHA-256 manifest. No private database or model weights are needed to run the default demo.

This is a TRL 3 research prototype and a completed technical disclosure for faculty review. The full frozen specification is not fully implemented: ANN topology repair and an efficient certified candidate method remain absent. Patent grant, novelty clearance and the intended cost-quality advantage are not established. The disclosure intentionally reports the negative measurements as well as the passing software checks.
